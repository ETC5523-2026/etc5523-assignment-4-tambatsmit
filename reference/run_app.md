# Run the electricity mix app

Launches a Shiny app that helps an energy policy analyst compare how
quickly countries are changing where their electricity comes from. The
app uses
[electricity_mix](https://etc5523-2026.github.io/etc5523-assignment-4-tambatsmit/reference/electricity_mix.md)
and
[`share_change()`](https://etc5523-2026.github.io/etc5523-assignment-4-tambatsmit/reference/share_change.md).

## Usage

``` r
run_app()
```

## Value

No return value; called for its side effect of launching the app.
